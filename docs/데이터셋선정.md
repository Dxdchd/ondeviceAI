# 데이터셋 선정 기록

현재 연구계획의 첫 데이터셋은 **CUB-200-2011**이다. 추가 두 개는 사용자가 조사하여 선정한다. 10월 29일 pilot은 CUB-200으로 진행하고, 추가 데이터셋은 후속 비교에 사용한다.

찾는 대상은 서로 다른 클래스 사이에 외형이 비슷해 구별하기 어려운 사진이 충분한 이미지 분류 데이터셋이다. 단순히 동일 이미지가 중복된 데이터셋과 구분한다.

## 조사할 때 남길 근거

- 공식 배포 페이지, 데이터 버전, 확인 날짜와 다운로드 가능 여부.
- 비슷한 클래스 여러 쌍의 이름과 이미지 ID. 무엇을 보고 구분하는지 짧은 관찰 메모.
- 각 클래스의 표본 수와 분할별 포함 여부. 동일 개체나 거의 같은 사진이 분할 사이에 섞이는지 확인.
- 제한된 학습 예산으로 Teacher와 Student를 반복 학습할 수 있는지.
- CUB-200과 다른 대상에서도 연구 질문을 검증할 수 있는지.

육안으로 고른 유사 클래스 예시는 선정 근거다. 최종 평가용 Hard-class 목록은 별도로 B-0 Teacher의 validation 결과를 사용해 정한다.
