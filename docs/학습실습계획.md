# 학습과 프로젝트 실습

기준 강의는 DeepLearning.AI의 [PyTorch for Deep Learning](https://www.deeplearning.ai/specializations/pytorch-for-deep-learning-professional-certificate)이다. 공식 개요의 Fundamentals에는 PyTorch 시작, Workflow, Data Management, Core Neural Network Components가 있고, 다음 과정에서는 TorchVision과 학습 효율화 등을 다룬다.

아래는 그 개념을 이번 이미지 분류 연구에 적용한 실습 순서다. 강의 과제나 주차를 그대로 복제한 목록은 아니며, pruning과 KD는 프로젝트 확장 단계다.

## 직접 구현할 순서

| 단계 | 직접 연습할 내용 | 다음 단계로 가기 전에 확인할 것 |
| --- | --- | --- |
| 1. 환경과 Tensor 복습 | 실행 환경 기록, shape, dtype, device 이해 | 이미지 배치와 라벨의 형태를 설명할 수 있음 |
| 2. 데이터 파이프라인 | 이미지와 라벨 확인, 분할, transform, Dataset, DataLoader | 이미지와 라벨이 맞고 train/validation/test가 겹치지 않음 |
| 3. 학습 Workflow | 모델 출력, loss, optimizer, 역전파, 학습과 평가 모드 | 작은 학습 부분집합에서 loss가 줄어드는지 확인 |
| 4. Student Baseline | 사전학습 모델과 분류 head, 학습과 검증, 저장과 복원 | KD 없는 결과와 학습 곡선을 기록 |
| 5. B-0 Teacher | Teacher 가중치 확인과 fine-tuning | 검증 결과로 체크포인트를 선택하고 혼동 클래스 확인 |
| 6. B-30 Teacher | 채널 제거 방식 이해, pruning 후 fine-tuning | 구조가 실행되고 실제 parameter/MACs 변화가 확인됨 |
| 7. Knowledge Distillation | 고정 Teacher, CE와 KD 항의 역할, Student 학습 | B-0/B-30에서 개별 loss와 정확도를 함께 기록 |
| 8. 평가와 배포 준비 | FP32/INT8 비교, 이후 Android CPU 지연 측정 | 동일한 평가 데이터와 측정 절차로 비교 |
| 9. 연구 확장 | 추가 데이터셋 두 개, 비율 확대와 반복 실험 | 데이터셋별 같은 비교 원칙을 적용하고 평균과 표준편차 기록 |

각 단계는 **개념 설명 → 사용자가 직접 작성 → 작은 실행 확인 → 결과 해석 → 기록** 순으로 진행한다. AI에는 막힌 개념이나 오류를 좁혀 질문한다.

## CUB-200 크기 조정 결정

- 결정: 가로세로 비율을 유지해 크기를 맞춘 뒤 padding을 넣는다. 중앙 자르기는 기본 전처리로 사용하지 않는다.
- 근거: 사용자가 비교한 사진에서 중앙 자르기로 새의 일부가 반복적으로 잘리는 것을 관찰하여, 원본에 포함된 새의 모습을 보존하기로 했다.
- 현재 실습 설정: 224×224 출력, bilinear 보간, 중앙 배치, 회색 RGB (128, 128, 128) 여백.
- 이 결정은 시각적 정보 보존에 근거한다. 두 방식의 분류 정확도 비교는 아직 수행하지 않았다.
- 이후 어그멘테이션도 중요한 신체 부위를 보존하려는 목적에 맞춰 선택한다. RandomResizedCrop 등 자르기를 포함한 변환을 자동으로 추가하지 않는다.
- Teacher의 입력 해상도와 모델별 정규화 설정은 모델 준비 단계에서 별도로 확인한다.

## 비교 전에 정할 기준

- 공식 test는 최종 평가용으로 남긴다. validation이 따로 없으면 학습 데이터에서 분리하고 목록을 저장한다.
- 데이터셋별 B-0 Teacher의 validation 혼동 결과로 Hard-class를 선정한다. 선정 규칙과 클래스 목록을 고정한 뒤 모든 조건의 test에 적용한다.
- 같은 반복 seed 안에서는 Student 초기 가중치와 학습 조건을 맞춘다. Baseline도 대응되는 반복을 두어 KD Gain을 비교한다.
- 제안한 30% 등의 비율이 어떤 채널 집합의 제거율인지 명시하고, 실제 전체 parameter/MACs 감소율을 별도로 측정한다.
- INT8 방식, calibration 데이터 출처, backend와 평가 장비를 기록한다. calibration이나 설정 선택에 test를 사용하지 않는다.
- Hard-class 수, 허용 가능한 정확도 하락 폭, 반복 seed, 학습 예산은 아직 미정이다. 실험 전에 팀에서 정한다.
