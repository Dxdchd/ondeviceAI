# 연구 동기

좋은 On-device Student를 만들기 위해 Teacher가 반드시 클 필요가 있는지
Teacher compression–KD quality trade-off 관점에서 분석

Teacher를 Structured Pruning으로 단계적으로 압축하고, 각 Teacher로 동일한
MobileNetV3 Student를 Knowledge Distillation하여 Student 성능 변화를 비교

Teacher parameter/FLOPs 감소 대비 Student의 Overall Accuracy와
Hard-class Accuracy가 어느 수준까지 유지되는지 분석


# 예상

Teacher Pruning ratio가 증가해도 일정 구간까지 KD Student의 성능은
유지될 것으로 예상

과도한 Pruning에서는 Teacher의 정보 손실로 Student의 Overall Accuracy와
Hard-class Accuracy가 감소할 것으로 예상


# 데이터셋

CUB-200-2011

- 200개 bird class의 Fine-grained Image Classification
- 유사한 class가 많아 Teacher compression에 따른 세밀한 분류 성능 변화 분석에 적합


# 모델

### Teacher: DINOv3 ConvNeXt-B

- Pretrained weight 사용
- CUB-200용 200-class Classification Head 적용
- Structured Pruning + Fine-tuning 적용

### Student: MobileNetV3-Large

- 모바일 환경을 위한 경량 CNN
- ImageNet pretrained weight 사용
- CUB-200용 200-class Classification Head 적용
- 모든 실험에서 동일한 architecture 사용


# 실험 구조

Teacher 조건:

0%: Teacher → Fine-tuning
30%: Teacher → Pruning → Fine-tuning
50%: Teacher → Pruning → Fine-tuning
70%: Teacher → Pruning → Fine-tuning

Pruning ratio는 pilot 실험 결과에 따라 조정

각 Teacher를 이용하여 동일한 MobileNetV3-Large에 Logit-based KD 적용

추가 Baseline:

MobileNetV3-Large를 KD 없이 동일한 조건으로 학습하여 KD 효과 비교


# 핵심 비교

Teacher Pruning ratio 증가에 따른

- Teacher Parameter 감소
- Teacher FLOPs/MACs 감소
- Student Overall Accuracy 변화
- Student Hard-class Accuracy 변화
- KD Gain 변화

분석

Teacher compression을 어느 수준까지 적용해도 Student 성능이 유지되는지 분석


# 연구 질문

RQ1:
Teacher의 Parameter/FLOPs를 줄여도 동일한 품질의 On-device Student를 만들 수 있는가?

RQ2:
Teacher Pruning ratio가 증가할 때 KD Student의 Overall Accuracy와
Hard-class Accuracy는 어떻게 변화하는가?

RQ3:
Teacher compression과 KD Student 성능 사이의 trade-off 지점은 어디인가?


# Pruning

Teacher에 L1-norm based Structured Pruning 적용

ConvNeXt block의 MLP expanded hidden channel을 Pruning 대상으로 설정

각 channel의 L1 norm을 importance로 사용하여 중요도가 낮은 channel부터 제거

$$
I_{l,c} = \sum_k |W_{l,c,k}|
$$

Student에는 Pruning 미적용


# Knowledge Distillation

Logit-based Knowledge Distillation 적용

Teacher는 freeze하고 Student만 학습

모든 Teacher 조건에서 동일한 Student 초기화 및 학습 조건 적용

각 조건에서 Student를 3회 반복 학습하고 평균과 표준편차 측정

# Hard-class

0% Teacher가 validation set에서 혼동하는 유사 class들을 Hard-class로 선정

선정한 Hard-class는 모든 Teacher와 Student 평가에서 동일하게 사용

전체 Test set의 Overall Accuracy와 Hard-class에 해당하는 Test sample의
Hard-class Accuracy를 각각 측정


# KD Gain

KD 없는 MobileNetV3 Baseline 대비 KD를 통해 얻은 Accuracy 향상을 측정

$$
G_{KD}(r)=A_r-A_B
$$

$A_B$: KD 없는 Student Accuracy

$A_r$: Pruning ratio $r$의 Teacher로 KD한 Student Accuracy

Teacher compression 증가에 따라 KD Gain이 어떻게 변화하는지 분석


# 평가 지표

## 교수님 피드백 정리

1.  teacher가 왜 경량화되어야 하는지 잘 제시해주면 좋겠다.

teacher와 student 모델 간의 차이가 작아야 경량화에 대한 방법론이 더 잘 적용이 되지 않겠냐는 가정이 깔려 있는 듯 한데, 이에 대한 실험도 같이 보여주면 좋을 것 같다.
만약 위 실험이 잘 된다면 teacher 모델에 대한 경량화를 하는 것에 대한 motivation이 더 잘 설명되기 때문에 이후 실험에 대한 더 탄탄한 근거가 될 수 있다.

2.  Dataset의 종류를 최소 3개 이상으로 늘려서 진행해야 한다.

3.  teacher가 점점 pruning 되더라도 student의 성능을 유지할 수 있는 방법들이 제시되면 좋겠다.

4. 오늘 제시한 평가 방법들이 잘 설계되어 있었다.
